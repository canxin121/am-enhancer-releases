# AM HiFi

公开发布通道。应用源码保留在私有仓库；这里仅放构建配置、更新清单和发布说明。

- 版本固定：**0.1.0**，安装号 **4008**。
- 更新入口：Apple Music → 设置 → USB HiFi → 模块更新。
- 自动检查更新；下载后校验签名，交由 Android 确认安装。
